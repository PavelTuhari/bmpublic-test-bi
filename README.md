# BMPUBLIC — тестовая BI

Локальный отчёт по схеме `BMPUBLIC` на Autonomous AI Database. Интерфейс на русском, румынском и португальском (Бразилия). Подключение только на чтение, учётка `BMPUBLIC_BI`.

## Запуск

```text
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:8765/ . В шапке переключатель «Русский / Română / Português». На португальском для Бразилии страница показывает контакт Ivan Souza.

Если сервер отдаёт BI по префиксу, задайте его переменной `BMPUBLIC_PREFIX` (на установленном сайте это `/test-bi`).

## Секреты

Пароль и кошелёк в этот репозиторий не входят. Положите их в каталог `.secrets` рядом с `app.py`. Этот каталог указан в `.gitignore`.

* `.secrets/users.txt` — строка `BMPUBLIC_BI: пароль`
* `.secrets/wallet/` — распакованный кошелёк, внутри есть `tnsnames.ora`
* `.secrets/agent.md` — паспорт базы, в нём строка пароля кошелька

Если `.secrets` лежит на уровень выше программы, он тоже будет найден. Свой каталог задаётся переменной `BMPUBLIC_SECRETS`.

Как подключаться к базе, описано на http://130.61.108.5/bi/ . Псевдоним службы в кошельке: `adb26ai_medium`.
